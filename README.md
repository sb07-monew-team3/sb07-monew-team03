## 📌 프로젝트 소개
> **MoNew**는 사용자의 관심사를 기반으로 뉴스를 수집·제공하고,
기사에 대한 댓글·좋아요·활동 내역을 관리하는 **뉴스 큐레이션 서비스**입니다.
